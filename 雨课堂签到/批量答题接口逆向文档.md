## 二、核心 API 端点全量清单

### 2.1 答题核心接口

```
POST /api/v3/lesson/problem/answer          ← ★ 核心: 提交答案
POST /api/v3/lesson/problem/finish          ← 结束作答（通知服务器题目已完成）
POST /api/v3/lesson/problem/retry           ← 重新作答（教师允许重答时）
POST /api/v3/lesson/problem/delay           ← 延时处理
POST /api/v3/lesson/problem/unlock          ← 解锁题目（特殊权限）

GET  /api/v3/lesson/problem/fetch-answer    ← 获取题目答案（结束后查看）
GET  /api/v3/lesson/problem/choice-detail   ← 获取选择题统计结果
GET  /api/v3/lesson/problem/blank-detail    ← 获取填空题详情
GET  /api/v3/lesson/problem/subj-result?problem_id=  ← 获取主观题结果
GET  /api/v3/lesson/problem/histogram       ← 获取答题分布直方图
GET  /api/v3/lesson/problem/subj-list-count ← 主观题提交计数
```

### 2.2 快速抢答 (RapidAnswer) 接口

```
POST /api/v3/lesson/rapid-answer/participate    ← ★ 参与抢答（提交抢答）

POST /api/v3/lesson/rapid-answer/end            ← 结束抢答（教师端）

GET  /api/v3/lesson/rapid-answer/score(         ← 抢答得分（注意括号是字符串的一部分）
```

### 2.3 课堂讲义与幻灯片

## 三、WSS (WebSocket) 事件驱动系统

雨课堂使用 WebSocket 在课堂中推送事件。学生端监听的关键事件名称：

| 事件名 | 描述 |
|--------|------|
| `WssSendsproblemOp` | 教师下发题目（★关键：触发"答题"流程）|
| `WssProbleminfoOp` | 题目详细信息推送 |
| `WssShowproblemremarkOp` | 显示题目备注 |
| `WssSproblemshownOp` | 已显示题目 |
| `WssGroupAnswerUpdate` | 小组答案更新 |
| `WssNavtoslideOp` | 幻灯片翻页（关联 slideId）|
| `detectlesson` | 检测课堂状态 |
| `enterlesson` | 进入课堂 |
| `leavelesson` | 离开课堂 |

WebSocket 连接信息：
- 字段：`wssUrl`（在课堂 `/api/v3/lesson/basic-info` 响应中获取）
- 心跳事件：`crateHeartBeat` / `HeartBeat`
- 连接初始化：`init:wssUrl`

## 四、题目答案提交接口详解

### 4.1 通用选择题/判断题答案提交
**接口**: `POST /api/v3/lesson/problem/answer`

从逆向分析中获取的关键字段名：

```json
{
  "problem_id": 123456,          // 题目 ID（从 WssSendsproblemOp 推送中获取）
  "answers": ["A"],              // 答案选项列表（单选传一个，多选传多个）
  "type": 0,                     // 题目类型（见下方类型表）
  "slide_id": 789,               // 幻灯片 ID（可选）
  "lesson_id": 456               // 课堂 ID
}
```

**题目类型码**（从 `slide.problem.type` 逻辑和 Dart 枚举推断）：
- `0` = 单选题 (SingleChoice)
- `1` = 多选题 (MultipleChoice)  
- `2` = 判断题 (Judgment)
- `3` = 填空题 (FillBlank)
- `4` = 主观题 (Subjective)

**必须携带的 Headers**：
```
Cookie: sessionid=...; sid=...; csrftoken=...;
x-csrftoken: <从 cookie 中提取>
x-uid: <用户 uid>
lessonToken: <签到时获取的 lessonToken>    ← ★ 关键！
user-agent: Android
x-client: app
xtbz: ykt
xtua: client=app&tag=1.3.3&platform=Android
brand: <随机手机品牌>
...（其他设备指纹 header）
```

> **关键提示**：`lessonToken` 是签到时服务端下发的高权限令牌，答题接口必须携带！

### 4.2 快速抢答参与
**接口**: `POST /api/v3/lesson/rapid-answer/participate`

```json
{
  "id": 123               // rapid_answer_id（从 rapid-answer/start 事件中获取）
}
```

响应中包含 `RapidAnswerInfo` 结构：包含 `lessonId`、`startTime`、`endTime` 等。

### 4.3 获取当前题目信息（主动轮询）
**接口**: `GET /api/v3/lesson/problem/choice-detail`

用于查询当前选择题的状态（是否已截止、是否已提交）。

## 五、课堂推送流程（关键！）

```
[签到完成] → 获取 lessonToken
     ↓
[连接 WebSocket] → wssUrl (来自 basic-info)
     ↓
[监听 WssSendsproblemOp 事件]
     ↓  事件携带: problemId, type, slideId, 选项列表
[调用 POST /api/v3/lesson/problem/answer]
     ↓  body: { problem_id, answers, type, slide_id }
     ↓  header: Cookie + lessonToken + x-uid
[获得答题成功响应]
     ↓
[触发 POST /api/v3/lesson/problem/finish] (可选，通知服务端答题完成)
```

## 六、逆向置信度与建议

### 高置信度（直接从字符串确认）
- ✅ 所有 API endpoint 路径
- ✅ Model class 名称（`ProblemAnswerBean`, `RapidAnswerBean` 等）
- ✅ `lessonToken` 字段名必须携带
- ✅ `problem_id` / `answers` / `type` 等 body 字段名（来自 camelCase/snake_case 提取）
- ✅ WSS 事件名（`WssSendsproblemOp` 等）
- ✅ 题型：单选/多选/判断/填空/主观/抢答

### 中置信度（需要实测验证）
- ⚠️ answers 字段是否为数组还是字符串（`["A"]` vs `"A"`）
- ⚠️ 题目类型码的具体数值（0/1/2/3/4 需验证）
- ⚠️ lessonToken 是放在 Header 还是 Body 里

### 建议验证方案
1. **HttpCanary + 真机** 的组合：用真正账号进入课堂，捕获一次答题请求的 Header 和 Body，可以精确确认字段格式。
2. **Blutter 完整反编译**：在 Linux 环境下运行 `blutter` 工具对 `libapp.so` 进行完整的 Dart snapshot 解析，可以获得完整的 Dart AST，直接还原出原始 Dart 代码逻辑。

## 八、批量答题 Vue/Kotlin 实现思路

基于以上逆向结果，批量答题的实现方案：

```javascript
// 批量答题核心函数
const batchSubmitAnswer = async (accounts, problemInfo) => {
  const { problemId, type, correctAnswers, slideId } = problemInfo;
  
  const tasks = accounts.map(acc => {
    return submitAnswer(acc, problemId, type, correctAnswers, slideId);
  });
  
  return await Promise.all(tasks);
};

const submitAnswer = async (acc, problemId, type, answers, slideId) => {
  const csrf = extractCsrfFromCookie(acc.cookie);
  
  const headers = {
    'cookie': acc.cookie,
    'x-csrftoken': csrf,
    'x-uid': acc.uid,
    'lessonToken': acc.lessonToken,   // ← 签到时缓存的 token
    'user-agent': 'Android',
    'x-client': 'app',
    'xtbz': 'ykt',
    'content-type': 'application/json',
    ...acc.device  // 设备指纹
  };
  
  const body = {
    problem_id: problemId,
    answers: answers,      // 如: ["A"] 或 ["A", "C"]
    type: type,            // 题型码
    slide_id: slideId,
  };
  
  // 重试机制
  for (let i = 0; i < 3; i++) {
    const res = await uni.request({
      url: 'https://www.yuketang.cn/api/v3/lesson/problem/answer',
      method: 'POST',
      header: headers,
      data: body
    });
    if (res.data?.code === 0) {
      return { success: true, name: acc.name };
    }
    await sleep(800);
  }
  return { success: false, name: acc.name };
};
```
