# 雨课堂助手 V2.1 改进版

## 1. 固定约束

- App 云同步地址继续使用 `http://IP:5000`。
- 批量签到、客户端手动答题、云端 AI 答题默认并发均为 16。
- 手动答题和 AI 托管完整并存：
  - `ai_mode=false`：进入客户端手动勾选和批量提交队列。
  - `ai_mode=true`：进入服务端 `ykt_ws_engine.py` 自动求解队列，并从手动队列排除。

## 2. 服务端组件

### `api_server.py`

- Waitress HTTP 服务，默认 24 个 HTTP 工作线程。
- 管理员口令由 `YKT_ADMIN_KEY` 提供；未配置时首次启动生成 `.admin_key`。
- 普通租户 Key 以 SHA-256 摘要保存，Key 对应独立 `tenant_id`。
- `/api/sync/*`、`/api/ai/history` 均按租户隔离。
- 上传使用字段级合并，普通同步不会再强制执行 `expired=false`。
- AI 图片 URL 启用协议、域名、公网 IP、Content-Type 和体积校验。

### `safe_json_store.py`

- 维持现有 JSON 数据格式。
- 线程锁 + 进程文件锁。
- 临时文件写入、`fsync`、原子替换。
- Windows `os.replace` 文件占用退避。
- 自动保留 `.bak`；JSON 损坏时保留 `.corrupt-*`，并中止覆盖。

### `ykt_monitor.py`

- 16 路并发账号探针。
- 有效性分为 `valid / expired / unknown`。
- 网络、网关、WAF 等临时问题进入 `unknown`，保持原有效性状态。
- 明确的 401、403、登录页和身份接口失败才标记 `expired`。
- PushPlus Token 改由环境变量提供。

### `ykt_ws_engine.py`

- 每个 `group_key + lessonId` 建立独立 `LessonRuntime`。
- 课堂 runtime 包含 generation、当前探针、WebSocket、heartbeat、题目任务和关闭集合。
- AI 推理通过 `asyncio.to_thread` 执行，避免阻塞 WebSocket。
- AI 提交使用 16 路 `Semaphore`。
- `problemfinished` 立即取消对应 AI/提交任务。
- `lessonfinished` 仅清理当前租户、当前课堂的凭证。
- 题目状态持久化到 `problem_states.json`，重启后跳过已经完成的题目。

## 3. App 组件

### 账号有效性

- 登录成功后必须通过 `user_info` 拿到有效 `user_profile` 才写入账号。
- 登录失败、网络失败均不会再创建“幽灵账号”。
- 本地账号探针使用 16 路有界并发。
- 云同步上传采用 500ms 防抖。
- 同步失败显示真实错误；本地备份模式明确提示。

### 手动答题

- 默认账号面板折叠。
- 当前课堂内可手动账号默认全选。
- AI 托管账号保持显示，但从手动选择队列排除。
- 题目元数据缺失时不再伪造 A-F 选项。
- 提交前逐账号复核 lessonId、problemId、题目状态和倒计时。
- 16 路提交，每个账号异常独立处理。

### WebSocket 生命周期

- 探针必须匹配当前 lessonId。
- hello 失败按真实 `activeProbeUid` 切换。
- 题目关闭后，尚未发出的手动请求自动跳过。
- 课堂结束只清理当前 lessonId。
- 缓存课堂超过 6 小时不再冷启动自动恢复。
- failover、倒计时、课件重试、冷启动 timer 均在停止或卸载时清理。

## 4. 配置与启动

复制 `.env.example` 中的变量到服务运行环境。项目本身不自动读取 `.env`，可由 systemd、Docker、PowerShell 或 Shell 注入。

Windows PowerShell 示例：

```powershell
$env:YKT_ADMIN_KEY = "换成足够长的管理员口令"
$env:GEMINI_API_KEY = "你的 Gemini Key"
$env:YKT_BATCH_CONCURRENCY = "16"
python -m pip install -r requirements.txt
python api_server.py
```

另一个终端启动 AI WebSocket：

```powershell
$env:GEMINI_API_KEY = "你的 Gemini Key"
$env:YKT_BATCH_CONCURRENCY = "16"
python ykt_ws_engine.py
```

账号巡检：

```powershell
$env:PUSH_PLUS_TOKEN = "你的 PushPlus Token"
python ykt_monitor.py
```

首次未配置 `YKT_ADMIN_KEY` 时，`api_server.py` 会在控制台打印一次生成的管理员口令，并写入 `.admin_key`。App 管理员控制台输入该口令完成在线验证。

## 5. 测试

```powershell
python -m unittest discover -s tests -p "test_*.py" -v
node tests/account-validity.test.mjs
node tests/answer-engine-utils.test.mjs
node tests/answer-engine-context.test.mjs
```

覆盖范围：

- 线程及多进程并发写入。
- 未登记 Key 拒绝。
- admin/tenant 权限分离。
- 租户数据隔离。
- expired 字段保持。
- SSRF 私网地址拒绝。
- `problemType=0`。
- 探针课堂隔离。
- 课堂结束范围清理。
- 手动与 AI 托管队列隔离。
- 跨课堂 WebSocket 消息过滤。
